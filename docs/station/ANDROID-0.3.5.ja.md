# Android 0.3.5 — アシスタント内の作業

2026-11-23。対象は experimental/android-client の開発署名APK。既存5施設のPi、Goハブ、Lite本番サーバーの配布・設定は変更しない。

## 変更

- ホームは搬入登録／ラベル印刷／在庫登録／スキャンの4項目。定期報告・設定は補助操作に分離。会話開始後にホームメニューがフェードアウトする。顔はマイクのオン／オフ、長押しと枠は廃止。
- アシスタントの作業から業務WebViewへ遷移しない。既存の業務タブは移行中の明示的な選択肢として残す。Androidの戻るも作業→ホーム→アプリを背景へ、の順にする。
- 在庫は精肉／加工品／ペットフード。実際の製品マスターを選択し、精肉は安定した計量値を取得できる。製品候補は12件ずつ表示し、残りもページ送りで選べる。製品マスターを勝手に新規作成しない。
- スキャンは出庫／印刷に分岐。出庫は施設内の精肉在庫を読み、確認後に既存の出庫APIを呼ぶ。個体番号だけでは出庫対象ロットを推測しない。
- 搬入、在庫、出庫、日報／週報／月報は確認後に既存のdurable APIを呼ぶ。日報の冷蔵庫・冷凍庫は施設設定から生成し、温度を既定値で確定しない。日報登録後、その日報に紐付く従業員健康チェックを追加できる。
- 作業中の明確な「記録者は…」「温度は…」等はそのフォームへ反映。登録・印刷の実行を発話の「はい」で承認しない。複雑な定期報告の自由発話抽出は未実装で、項目名と値、または画面入力を使う。
- 設定は機器・音声／Gemini・接続先をアシスタント内から開ける。施設マスターは参照のみで、編集APIの移植はまだ行っていない。
- テキスト検索・文字入力・数値入力の右にクリア操作を追加。

## 認証・確定・通信

補助Cookie __session_exists だけでアシスタントの可否を決めない。FirebaseのIDトークンを既存APIで検証し、現在施設APIから施設IDを確定する。通信後にIDと選択施設を読み直し、途中のログアウト／切替を拒否する。IndexedDBの初期化待ちを有限回行う。トークン・キーはWeb UIや永続受付へ渡さない。

登録内容は確認したスナップショットと受付IDを通信前にアカウント・施設単位で保存する。タイムアウト／プロセス再起動後は同じ受付ID・同じ内容でdurable APIに結果を確認する。新しい登録を無条件に送らない。受付未確認中は内容を変更できない。業務APIのURL・操作種別はネイティブ側の固定リストに限定する。

印刷は既存施設ハブの /printer/print を使用する。確認した施設情報が変わった場合は送信を止める。トレーサブルラベルのQRは登録済み個体の照会結果から生成する。印刷前に端末へ送信記録を同期保存し、結果不明でも再起動後に自動再送しない。画面で出力確認後に次の印刷へ進む。ハブの受理と物理的な印字確認は区別する。この版の印刷接続を、Androidからプリンタへの直接Bluetooth接続と混同しない。

## 計量

USBは既存FTDI対応モジュール（VID 0403/PID 6015）、2400bps・7E1。BluetoothはAndroidでペアリングしたClassic SPPアダプタのみ。RS-232側がA&Dのコマンド／2400bps・7E1に対応する必要があり、BLE専用やUSBモジュール単体を無線化するものではない。各読み取りは古い入力を捨ててQを要求し、安定応答だけを利用する。画面を離れた後の値は捨て、自動で別の接続方式へ切り替えない。

## 検証と残件

- npm test：入力解釈、割り込み、年月日／単位、候補、永続受付の復元・同一ID再照会・保存失敗時の送信禁止を確認。
- Android assembleDebug、assembleDebugAndroidTest、lintDebug：成功。clientCore 23テスト成功（変更なしのためキャッシュ利用）。
- Androidエミュレーター：20テスト成功。認証拒否、固定API経路、印刷の結果未確認記録、ホーム・候補・在庫／週報・キーボード表示、既存USB経路を検証。最終UI修正後も関連6件、カード配置の最終調整後にUI2件を再実行し成功。
- 初回の全体実行ではLoginGateのフィクスチャ読み込み待ちが失敗した。URLコールバック依存からフィクスチャDOMの確認に変更し、全20件が成功した。認証の許可条件を緩めて解消したものではない。
- 登録・印刷の本番送信はテストで行っていない。実施設のAPI応答、既存データとの整合、帳票全項目、物理印刷・スキャン・USB／Bluetooth計量、長時間運転は実機での次段階検証が必要。
- 接続できたAndroidは emulator-5554 のみ。LAVIE/Pixelの実機動作を確認済みとは扱わない。完全安定・本番同等機能の達成とはしない。
- 施設マスター編集、帳票の既存記録編集／一覧、特殊なラベル販売者設定、印刷の直接Bluetooth経路は残件。
